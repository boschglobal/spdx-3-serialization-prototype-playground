# Example 05 Export Control Assessment Operation

## Description
This example shall provide insights how the business operations profile could be used in the context of an export control assessment.

### Boundaries

DeliverableFrom: LLVM Project
ProjectName: Clang
Purpose: Provides a compiler front end for C language family languages.
CountryOfOrigin: Germany

### Assessment

In order to prepare a delivery to another country, the organization has to assess the export control requirements and determine the respective Export Control number
